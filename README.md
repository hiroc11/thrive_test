# thrive_test

## 増殖ラン（プロトタイプ）
広告でよく見る「ゲートを選んで仲間を増やす」系ランナー。`index.html` をブラウザで開くだけで遊べます（サーバー不要）。

- 左右ドラッグ / 矢印キーでゲートを選ぶ（+ / × は増える、- / ÷ は減る）
- 赤い敵の群れにぶつかると人数が減る
- ゴールのボスより人数が多ければクリア → 次のレベル

## ぷくホロシール帳（質感デモ）
`sticker-demo/index.html` をスマホで開き、傾けるかシールを指でなぞるとホロ・ぷっくり・ラメが光ります。
（`sticker-demo/sticker.html` は Artifact 公開用の同じ中身で、`<head>` なし版です）
