# ふたりの暮らし

夫婦の関係をよくするためのスマホ向けWebアプリ（PWA）です。
ふたりのスマホで、家事分担・買い物リスト・ありがとう・記念日を**自動で同期**します。

## 機能

画面下のタブは「ホーム・家事・買い物・ふたり・その他」の5つです。

- **家事**
  - よくある家事（約40種類）をカテゴリから選んで追加できます
  - 予定は「n日ごと」か「曜日指定（例: 月・木）」で決められます
  - 担当は、固定・毎回交代・毎週交代から選べます
  - 相手の担当を代わりにやると相手に伝わり、ワンタップで「ありがとう」を返せます
- **家事バランス**: 直近7日間にこなした家事のポイントを、ふたりで比べて表示します
- **買い物リスト・在庫チェック**: 日用品を「少ない」にすると、自動で買い物リストに入ります。買ったら在庫が「ある」に戻ります
- **ふたり**
  - 週のふりかえり（家事・ありがとう・お願いの回数）
  - お願い（引き受ける → やった！）
  - ありがとう（❤️😊🙏😂 でリアクション）
- **その他**
  - 記念日のカウントダウン
  - 家計簿（半分ずつ・立て替え・自分の分を記録して精算）
  - 共有メモ（Wi-Fi、ゴミの分別など）
  - 設定
- **通知（Web Push）**
  - 朝の家事リマインド（時刻は自分で決められます）
  - 記念日（7日前・3日前・当日）
  - 買い物リストに追加されたとき
  - ありがとう・お願い・代わりにやったとき
  - 日曜夜のふりかえり
  - iPhone では、ホーム画面に追加したアプリから開くと使えます（iOS 16.4 以降）
- **ふたりの同期**: 共有コードで2台をつなぐと、変更が数秒で相手に届きます。オフラインのときの変更は、つながったあとに送信されます

## 動かし方

Node.js 18 以上が必要です。

```sh
npm install
npm start
# → http://localhost:8080 を開く
```

環境変数:

| 名前 | 既定値 | 説明 |
| --- | --- | --- |
| `PORT` | `8080` | 待ち受けポート |
| `DATA_DIR` | `./data` | ふたりのデータ（ルームごとの JSON）の保存先 |
| `TRUST_PROXY` | なし | `1` にすると、プロキシが付けた接続元 IP を使います（Fly.io など） |
| `TZ` | システムの設定 | 朝の通知などの時刻のタイムゾーン（例: `Asia/Tokyo`） |
| `VAPID_SUBJECT` | `https://<FLY_APP_NAME>.fly.dev` | プッシュ通知の送信者を表す URL または `mailto:` |

通知の暗号鍵（VAPID）は、初回起動時に `DATA_DIR/vapid.json` に自動で作られます。

## ふたりの端末をつなぐ

1. サーバーをインターネットに公開します（下記）
2. 1人目がスマホでアプリを開き、**設定 → はじめる（コードを作る）** を押します
3. 表示された10文字のコードを、2人目が **設定 → コードで参加** に入力します
4. 以後はふたりの変更が自動で同期されます。右上の丸が緑なら同期済みです

つなぐ前にそれぞれの端末で入力していたデータは、両方ともまとめて残ります。

## 公開（デプロイ）

**Fly.io（東京リージョン）へのデプロイ手順は [DEPLOY.md](DEPLOY.md) にあります。** 設定は `fly.toml` に入っています。

ほかのサービスでも、Docker が動けば `Dockerfile` で動かせます。
その場合は、**`/data` を永続ディスク（ボリューム）にしてください。** そうしないと、再起動でデータが消えます。
プロキシの後ろで動かすときは、`TRUST_PROXY=1` を設定してください。

アプリだけを GitHub Pages などに置く場合は、設定画面の「同期サーバーのURL」にサーバーのURLを入れてください。

## しくみ

- 各データは `{ id, updatedAt, deleted? }` を持つレコードです。同期ではレコード単位で、新しく更新された方を採用します（Last-Write-Wins）
- 削除は `deleted: true` のレコードとして記録し、相手にも伝えます
- 家事の「最後にやった日」は完了記録から計算しています。そのため、ふたりが同時に完了しても記録は消えません
- サーバーは変更に連番（rev）を振り、端末は前回以降の差分だけを受け取ります。相手に変更を知らせるには Server-Sent Events を使います
- 「この端末を使う人」は同期しません。端末ごとの設定です
- 家事の予定計算（`app/logic.js`）は、アプリとサーバーの両方で使います。サーバーはこれを使って朝の通知の内容を作ります
- 通知は、変更から6時間以内のものだけ送ります。同期に参加したときにまとめて届く古いデータでは送りません

### セキュリティについて

共有コードを知っている人は、そのデータを読み書きできます。コードは他人に教えないでください。
（コードは32種類の文字からなる10文字で、約10^15通りあります。ルームの作成数は、IP アドレスごとに1時間20件までに制限しています。）
