# ふたりの暮らし

夫婦の関係をよくするためのスマホ向けWebアプリ（PWA）です。
ビルド不要で、静的ファイルを置くだけで動きます。

## 機能

- **家事分担**: 担当（自分／相手／ふたり）・頻度・大変さ（ポイント）を設定。完了すると記録され、期限切れの家事がホームに出ます
- **家事バランス**: 直近7日間にこなした家事のポイントを、ふたりで比べて表示します
- **買い物リスト**: 誰が追加したかがわかる共有リストです
- **ありがとう**: 相手への感謝を書いて残せます
- **記念日**: 結婚記念日や誕生日までのカウントダウン（「何回目」も表示）
- **操作者の切り替え**: 右上のボタンで、自分と相手を切り替えられます
- **バックアップ**: JSON の書き出し・読み込み

## 動かし方

```sh
cd app
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

スマホでは、同じWi-Fiにつないで PC の IP アドレス:8000 を開き、「ホーム画面に追加」するとアプリのように使えます。
GitHub Pages などで公開すれば、どこからでも使えます。

## 現状の制約と今後

- データは端末の localStorage にだけ保存されます。ふたりの端末でリアルタイムに同期するには、バックエンド（Firebase / Supabase など）が必要です
- 今後の案: 端末間の同期、プッシュ通知（家事のリマインド・記念日）、家計簿、週ごとのふりかえり
