# 週次の振り返り

## 入力

`data/analytics/` に YouTube Studio →「アナリティクス」→「詳細モード」→ 書き出し（CSV）を置いてもらう。
推奨の列: 動画タイトル / 公開日 / 視聴回数 / 総再生時間（時間） / 平均視聴時間 / 平均再生率 /
インプレッション数 / インプレッションのクリック率 / 登録者の増減 / 推定収益。
CSV が無ければ、置き場所と書き出し手順を案内して終了する。

## 分析すること

1. 長尺とショートを分けて、各動画の数字を表にする
2. **クリック率**（サムネ・タイトルの評価）と **平均再生率**（台本の評価）で上位・下位を比べ、
   対応する `content/*/script.json` の title / thumbnail.text / format / 冒頭の区間と照らし合わせる
3. フォーマット別の平均（どの型が伸びるか）
4. 収益化条件への進捗: 登録者 1,000人 / 直近12か月の総再生時間 4,000時間 に対する達成率と、今のペースでの到達見込み
5. 推定収益と RPM（1,000回あたり収益）の推移

## 出力

`reports/weekly-<YYYY-MM-DD>.md` に:

- 今週のサマリー（3行）
- 数字の表
- 伸びた理由・伸びなかった理由の仮説（データに基づくものだけ）
- **来週の提案**: 次に作るべきフォーマットとテーマ案3つ、タイトル・サムネの改善、冒頭の改善
  （make-episode はこの節を読んで次の台本に反映する）

レポートをコミットしてプッシュする。CSV に個人情報が含まれていないか確認し、含まれていればコミットしない。
