# 死亡フラグ素材

『死亡フラグが見える鑑定士』の編集用素材です。背景が透明なPNG（512×600）です。

| ファイル | 用途 |
| --- | --- |
| `flag_white.png` | 白（いつか）。少し半透明 |
| `flag_yellow.png` | 黄（近い） |
| `flag_orange.png` | 橙（中間） |
| `flag_red.png` | 赤（今日）。赤い光つき |
| `flag_black.png` | 黒（数分以内）。紫のオーラつき |
| `flag_<色>_broken_top.png` / `_broken_bottom.png` | 「ポキッ」用。竿の途中で上下2パーツに分かれている |
| `preview.png` | 確認用の一覧 |

## 編集での使い方（CapCutなど）

1. キャラの頭上、拳ひとつ分くらい上に旗を置く。竿の下端が頭の少し上に来る大きさに縮める。
2. 上下に数ピクセル、2〜3秒周期でゆっくり揺らす（キーフレームか「浮遊」系アニメーション）。
3. 旗の三角部分の中央に、筆文字フォントで漢字を乗せる。文字色は白い旗なら黒、それ以外は白か黒の読みやすいほう。
4. 色が変わる演出（赤→黒など）は、2枚を同じ位置に重ねてクロスフェードする。
5. 「ポキッ」は、通常の旗を `broken_top` と `broken_bottom` に切り替え、上パーツだけを回転させながら落とし、光の粒のエフェクトで消す。

## 作り直す場合

色や形は `tools/make_flags.py` で変えられます。

```
pip install pillow
python3 tools/make_flags.py
```
