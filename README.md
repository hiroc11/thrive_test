# thrive_test

## 増殖ラン（プロトタイプ）
広告でよく見る「ゲートを選んで仲間を増やす」系ランナー。`index.html` をブラウザで開くだけで遊べます（サーバー不要）。

- 左右ドラッグ / 矢印キーでゲートを選ぶ（+ / × は増える、- / ÷ は減る）
- 赤い敵の群れにぶつかると人数が減る
- ゴールのボスより人数が多ければクリア → 次のレベル

## ぷくホロシール帳（質感デモ）
`sticker-demo/index.html` をスマホで開き、傾けるかシールを指でなぞるとホロ・ぷっくり・ラメが光ります。切り取り線をなぞるとパックが開き、レア度（排出率 60/28/10/2%）に応じた演出でシールが出てシール帳に貼れます。
（`sticker-demo/sticker.html` は Artifact 公開用の同じ中身で、`<head>` なし版です）
「交換する」を押すと、友達（自動で動く相手役「ゆいな」）との交換テーブルが開きます。シールをドラッグかタップで出し合い、スタンプでかけひきし、2人ともOKなら「せーの」を長押しすると入れ替わります。
交換には「ふつう交換」と、1枚ずつふせて同時にめくる「ふせて交換」があります。
「友達とオンラインで交換」は claude.ai で公開したページ上でだけ動きます（Artifact の `room` 機能）。同じページを開いた2人が同じ4けたのコードを入れるとつながり、出したシールや「せーの」がリアルタイムで相手に届きます。ふせて交換では中身のハッシュだけ先に送り、2人のせーの後に中身を明かすので、めくるまで相手には分かりません。手持ちはそのブラウザにだけ保存されます。
「おすもうシリーズ」は、しこ名がすべて架空の力士シール5種（前頭2・関脇・大関・横綱）と、力士ニャンコ3種・力士ワンコ3種です。番付がレア度に対応していて、パックから出ます。
エフェクトは9種類（ホロ・ぷっくり・ラメ・オーロラ・ジェル・プリズム・メタリック・チェンジング・シークレット）で、「エフェクト図鑑」で見比べられます。指やマウスが乗っているシールだけが傾きます（何も触らずに2.5秒たつと、全体がゆっくり揺れます）。
シール帳のシールは長押しで持ち上げて並べ替えられます（拡大表示の「前へ／次へ」でも可）。並び順はブラウザに保存されます。上下左右のとなりに誰がいるかで、吹き出しのセリフが変わります（例：力士ニャンコは力士のとなりだと「ちょっと怖いにゃ…」）。
収益化の仕組み（デモ用のアプリ内通貨「キラ」で動作。本当の課金はありません）：
- 天井：10パックごとにレア以上確定、Sレア以上が49パック出なければ50パック目で確定。残りパック数をメーターで表示。
- デコショップ：台紙5種・マスキングテープ4種を購入して着せ替え。月の利用上限（保護者設定）つき。
- ギフト：メッセージカードつきでゆいなにパックを贈ると、あとでお返しのギフトが届いて開封できる。
「いろいろシリーズ」として、ぷくドロップ（厚い透明樹脂ドーム：くま・リボン・ハート）、シンプル（光らない紙素材：おにぎり・よつば・にこにこ）、おしり（しば・ねこ・もも）を追加。
シールを押すと、素材のやわらかさに応じてつぶれ、指の位置がへこみ、離すとぷるんと戻って波紋が出ます。素材ごとに効果音（オン／オフ切替）と、対応端末では軽い振動があります。
毎日の仕掛け：1日1回の無料パック、ログインスタンプ（7こで限定シール「がんばりぼし」、休んでも消えない）、図鑑（一度手に入れたシールを記録して達成率を表示。そろえても景品なし）。デモ用に「1日進める」ボタンで日付を進められます。
