# ふたりの暮らし

夫婦の関係をよくするためのスマホ向けWebアプリ（PWA）です。
ふたりのスマホで、家事分担・買い物リスト・ありがとう・記念日を**自動で同期**します。

## 機能

- **家事分担**: 担当（自分／相手／ふたり）、頻度、大変さ（ポイント）を設定できます。完了を記録すると、期限が来た家事がホームに表示されます
- **家事バランス**: 直近7日間にこなした家事のポイントを、ふたりで比べて表示します
- **買い物リスト**: 誰が追加したかわかる共有リスト
- **ありがとう**: 相手への感謝を残せます
- **記念日**: カウントダウンと「何回目」の表示
- **ふたりの同期**: 共有コードで2台をつなぐと、変更が数秒で相手に届きます。オフラインのときの変更は、つながったあとに送信されます

## 動かし方

Node.js 18 以上が必要です（依存パッケージはありません）。

```sh
npm start
# → http://localhost:8080 を開く
```

環境変数:

| 名前 | 既定値 | 説明 |
| --- | --- | --- |
| `PORT` | `8080` | 待ち受けポート |
| `DATA_DIR` | `./data` | ふたりのデータ（ルームごとの JSON）の保存先 |

## ふたりの端末をつなぐ

1. サーバーをインターネットに公開します（下記）
2. 1人目がスマホでアプリを開き、**設定 → はじめる（コードを作る）** を押します
3. 表示された10文字のコードを、2人目が **設定 → コードで参加** に入力します
4. 以後はふたりの変更が自動で同期されます。右上の丸が緑なら同期済みです

つなぐ前にそれぞれの端末で入力していたデータは、両方ともまとめて残ります。

## 公開（デプロイ）

`Dockerfile` を使って、Docker が動くサービスならどこでも動かせます。
**`/data` は永続ディスク（ボリューム）にしてください。** そうしないと、再起動のたびにデータが消えます。

- Fly.io: `fly launch` のあと `fly volumes create data` を実行し、`/data` にマウント
- Render / Railway: Docker でデプロイし、Persistent Disk（Volume）を `/data` にマウント
- 自宅の PC / Raspberry Pi: `npm start` で起動し、Cloudflare Tunnel などで HTTPS 公開

スマホでは、公開した URL を開いて「ホーム画面に追加」するとアプリのように使えます。
アプリだけを GitHub Pages などに置く場合は、設定画面の「同期サーバーのURL」にサーバーのURLを入れてください。

## しくみ

- 各データは `{ id, updatedAt, deleted? }` を持つレコードです。同期ではレコード単位で、新しく更新された方を採用します（Last-Write-Wins）
- 削除は `deleted: true` のレコードとして記録し、相手にも伝えます
- 家事の「最後にやった日」は完了記録から計算しています。そのため、ふたりが同時に完了しても記録は消えません
- サーバーは変更に連番（rev）を振り、端末は前回以降の差分だけを受け取ります。相手に変更を知らせるには Server-Sent Events を使います
- 「この端末を使う人」は同期しません。端末ごとの設定です

### セキュリティについて

共有コードを知っている人は、そのデータを読み書きできます。コードは他人に教えないでください。
（コードは32種類の文字からなる10文字で、約10^15通りあります。ルームの作成数は、IP アドレスごとに1時間20件までに制限しています。）
